## 🧠 About Me

I'm a **Machine Learning Engineer with 3 years of experience** designing and developing intelligent, scalable, and real-world AI solutions.

My primary focus is on **Agentic AI, Generative AI, Large Language Models, Computer Vision, and production-grade machine learning systems**.

I enjoy transforming complex research concepts into reliable, efficient, and deployable applications — from autonomous AI agents and multi-agent orchestration to advanced image generation pipelines and intelligent computer vision systems.

- 🤖 **Agentic AI:** Autonomous agents, multi-agent orchestration, tool calling, memory systems, planning, and human-in-the-loop workflows.
- 🧠 **LLM Engineering:** RAG, LLM integration, prompt engineering, model fine-tuning, and structured AI workflows.
- 🎨 **Generative AI:** ComfyUI, FLUX, SDXL, LoRA training, image generation, and image manipulation pipelines.
- 👁️ **Computer Vision:** Object detection, OCR, image segmentation, tracking, and visual recognition.
- ⚙️ **AI Backend Engineering:** Python, FastAPI, REST APIs, asynchronous processing, and AI service integration.
- 🚀 **MLOps & Deployment:** Docker, cloud deployment, model serving, inference optimization, and API integration.
- 🔬 **Research Interests:** Multimodal AI, vision-language models, explainable AI, and efficient machine learning.

**My engineering philosophy:** Build AI systems that are intelligent, reliable, maintainable, and useful beyond the prototype stage.
